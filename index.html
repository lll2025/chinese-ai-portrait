教师说明：如何开启32人共享模式？

本文件已包含 Supabase 在线数据连接功能。本版本已连接课堂数据库。要实现全班跨设备共享，需要：

  1. 创建 Supabase 项目，在 SQL 编辑器执行随附的 ai_character_setup.sql。
  2. 本版本已经填入项目 URL 和 Publishable key，无需再次填写。
  3. 通过 HTTPS 静态网站（例如 GitHub Pages）发布此 HTML。学生访问同一个网址。

教师管理按钮在共享模式下只能在教师登录并且有对应数据库权限时操作。本示例为了易于部署，没有内置教师认证界面，推荐在 Supabase 管理后台手动设置投票阶段。切勿把 service_role 或 secret key 写入HTML。
